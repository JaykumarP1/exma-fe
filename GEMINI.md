# Workspace Guidelines & Rules

## In-Built Component Enforcement

- **In-Built Dropdown Policy**: Whenever and wherever a dropdown is used or added, you MUST ALWAYS use the in-built `<Select>` component from `src/components/ui/Select.tsx`.

## Code Commenting Policy

- **No Gratuitous Comments**: Do NOT add explanatory comments to every command, method, or line by default.
- **High-Value Comments Only**: Only add a comment when the logic is genuinely tricky, non-obvious, or involves important business/domain rules that aren't self-evident from the code (e.g. a workaround, a non-obvious edge case, a specific business rule).
- **Senior Developer Audience**: Assume the reader is a senior-level developer. Skip comments that just restate what the code says.
- **Focus on the "Why"**: Keep comments short, focused on the *why*, not the *what*.
